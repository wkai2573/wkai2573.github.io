▶ 點擊試玩

守燈人 · The Lamplighter

一段提著燈穿越長夜的 2.5D 橫向卷軸氛圍冒險。世界沉入長夜，你是最後的守燈人，收集螢火補充燈油、驅散暗影，點亮海崖燈塔迎來黎明。

  • Three.js 窄視角透視真實 3D 視差，點光源陰影隨角色走路擺錘物理搖晃
  • 解析積分自製霧氣體積散射（每盞燈的光暈都有真實體積感）、Bloom 與水面 Fresnel 反射
  • Web Audio API 純即時程序化音效、Karplus-Strong 撥弦生成式配樂
  • 無任何外部 3D 模型與音訊檔案，整包僅約 780 KB 毫秒級極速啟動

▶ 進入場景

雨夜便利商店與秋夜旅館

用 Three.js 手工程式建模的日式微縮場景集。收錄深夜下雨街角的便利商店，以及浮在晚秋夜空的溫泉旅館浮島。

  • 三渲二（Toon Shader 著色＋描邊）與低多邊形＋SSAO 柔和環境光遮蔽渲染
  • 動態天候與日夜光影：時間滑桿、晴雨雪切換、路面積水倒影與漸變融雪
  • 雙聲道 3D 空間定位環境音（店內入店鈴、屋簷水滴聲隨視角距離與方位切換）
  • 所有模型貼圖與動畫純程式產生，零外部模型檔案，零打包步驟原生運行

Deterministic Card Battle
▶ 線上對戰

晨昏戰線 Duskline

一局 10～15 分鐘的 1v1 策略卡牌對戰。白晝 ☀ 與黑夜 ☾ 每回合交替，卡片具備晝夜雙攻擊力，雙方在三條戰線上暗牌同時佈署、揭曉自動交戰。

  • 純函式規則引擎：所有狀態變更不可變、亂數種子完全可重現（Deterministic）
  • WebRTC (PeerJS) 免伺服器 P2P 對戰，點擊即開房、無須註冊直接連線
  • Commit-Reveal 雜湊防偷看協定與 Lockstep 鎖步雙向盤面雜湊校驗
  • 貪婪 AI 模擬對弈工具，千局模擬分析陣營勝率、平均回合數與先手偏差

▶ 連擊遊玩

連擊大師 Combo Master

以連擊值接力出招的 1v1 原創 TCG 網頁卡牌遊戲。具備直觀的節奏判定、即時連線對戰系統與全站雲端匿名戰績庫。

  • 動態戰鬥流程圖系統：戰鬥推進即時高亮「你在這裡」，追擊分支與判定清楚直觀
  • PeerJS 6 碼房號直接連線對戰，主客端狀態同步機制與作弊模式除錯中樞
  • Cloudflare Workers + D1 資料庫：全球匿名戰績雲端儲存與統計伺服器
  • 卡表與數值同步管線、機器人壓力測試與牌組連擊值分佈分析工具
